Getting started

Working on it locally

  1. Install Node 18 or newer and clone the repo.
  2. npm install pulls the Angular renderer and Electron shell together.
  3. npm start runs the Angular dev server and opens the Electron window against it, with live reload.
  4. Add an account under Connections → New. Credentials go to the OS keychain, not the repo.
  5. npm run dist produces signed-installer output in release/.
